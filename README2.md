# Random User Generator

This Python script generates random user data using the `randomuser` library.

## Features

* Generates random users
* Displays profile picture URLs
* Can also show name and email

## Requirements

* Python 3
* randomuser

## Installation

```bash
pip install randomuser
```

## Usage

Run the script:

```bash
python l.py
```

## Example Output

```
https://randomuser.me/api/portraits/women/21.jpg
https://randomuser.me/api/portraits/men/80.jpg
https://randomuser.me/api/portraits/men/4.jpg
...
```

## Description

This project uses an API to generate random user data and prints profile image URLs. It is useful for testing, learning APIs, and generating sample data.
