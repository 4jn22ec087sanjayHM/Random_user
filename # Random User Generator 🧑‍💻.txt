# Random User Generator 🧑‍💻

This is a simple Python project that generates random user data such as names and email addresses using the `randomuser` library.

## 🚀 Features

* Generate multiple random users
* Display full name and email
* Beginner-friendly Python script

## 📦 Requirements

* Python 3.x
* randomuser
* pandas (optional)

## 🔧 Installation

Install dependencies:

```bash
pip install randomuser pandas
```

## ▶️ Usage

Run the script:

```bash
python l.py
```

## 💡 Example Output

```
Daryl Reed - daryl.reed@example.com
Lígia Fogaça - ligia.fogaca@example.com
Hannah Barnaby - hannah.barnaby@example.com
...
```
